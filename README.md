# Seer — Six Instruments

Design concept for the **Seer** rebrand (poidh mainnet bounty #38), built as six static
demo pages sharing one design system (`seer.css`).

Starting point: the Electric Foundation brand kit; deliberate departures and rationale
are documented in the poidh claim description.

| # | Interface | File |
|---|---|---|
| 01 | Homepage — the protocol beneath the applications | `index.html` |
| 02 | Seer App — general market explorer | `app.html` |
| 03 | Deep — many-outcome fields, agent-tradeable | `deep.html` |
| 04 | Futarchy — conditional pass/fail markets | `futarchy.html` |
| 05 | Opportunity Markets — selection forecasts | `opportunity.html` |
| 06 | Risk Pricing — cross-protocol risk estimates | `risk.html` |

All prices, volumes and names shown are illustrative example data. No wallet is
connected and no transactions are possible on these pages.
